# Lost Sheep

*"Rejoice with me; I have found my lost sheep."* — Luke 15:6

A shepherd leads his flock across the pasture, gathering every lost lamb he
finds. Each lamb joins the line behind him, so the flock grows longer and
harder to steer. Built with HTML5 Canvas.

## How to Play

Open `index.html` in any modern browser — no build step, no dependencies.

| Input | Action |
|---|---|
| Arrow keys or WASD | Steer the shepherd |
| P | Pause / resume |
| Any arrow / WASD | Start or restart |

**Objective:** Reach each glowing lost lamb to bring it into the flock and increase your score. Avoid walking into the pasture's edge or into your own flock.

**Speed:** The flock moves faster every time a lamb is found — plan ahead!

Your best score is saved in `localStorage` and persists between sessions.
